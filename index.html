Proyecto Personal — Análisis Exploratorio de Datos y Visualización

Grado en Ciencias de Datos · Universidad de Las Palmas de Gran Canaria · Luis Álvarez

Empieza por la guía de trabajo del proyecto personal: explica las tres entregas, el flujo de trabajo paso a paso y la rúbrica de evaluación.

Para trabajar necesitas los ficheros en tu ordenador: descargar todo en un ZIP (~50 MB) o clonar el repositorio con git clone https://github.com/lalvarezmat/AEDV-proyecto-personal.git.

Documentos principales

  • Guía de trabajo del proyecto personal — entregas, seguimiento, flujo paso a paso y rúbrica comentada
  • Modelo de memoria (vista previa) — plantilla que se copia y se rellena: ModeloMemoriaProyectoPersonalAEDV.Rmd
  • Rúbrica de evaluación (xlsx) — 27 criterios en 7 áreas, por entrega
  • estilos.css — estilos de la memoria; se necesita junto al Rmd, no se modifica

Selección de datasets

Guía para la elección del tema y de los datos — criterios AEDV que deben cumplir los datasets del proyecto.

Para cada fuente hay dos documentos: TableDatasetGeneration construye el catálogo completo recorriendo la API, y DatasetSelection filtra, valida y analiza el dataset elegido.
